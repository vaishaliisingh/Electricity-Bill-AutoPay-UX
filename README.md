# Electricity-Bill-AutoPay-UX

## Overview

This project is a UX case study for designing a recurring electricity bill payment setup flow within a mobile banking application. The goal was to create a seamless, secure, and user-friendly AutoPay experience that minimizes cognitive load while maintaining user trust and control.

---

## Problem Statement

Design a mobile banking experience that allows users to easily set up automatic recurring payments for their monthly electricity bills.

The solution focuses on:

* Simplified navigation
* Clear payment configuration
* Error prevention
* Accessibility
* User trust and transparency
* Payment management flexibility

---

## Key UX Considerations

* Step-by-step guided flow
* Secure UPI PIN authentication
* Error handling and recovery flows
* FAQ and customer support integration
* Accessibility-friendly layouts
* Clear payment visibility and control
